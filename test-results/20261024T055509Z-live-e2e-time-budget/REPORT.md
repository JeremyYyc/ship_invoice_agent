## 验收判断

1. 应用层确实最多只重试一次；日志中没有 Provider SDK 自行重试。
2. 超时仅影响当前 `RawDocument`，不会中断同一邮件的其他附件。
3. 超时输出明确带有 `LLM_EXTRACTION_FAILED` 和
   `LLM_TIME_BUDGET_EXHAUSTED`，不会自动入账。
4. 鉴权失败、模型不存在及普通 Schema 错误不会被伪装成超时。
5. PDF2 的核心准确率没有因超时优化下降。
